# Heart Failure 30-Day Readmission Prediction

This project uses machine learning to predict whether a patient will be readmitted to the hospital within 
30 days following heart failure treatment.

Three classification algorithms are implemented and evaluated:

- **Logistic Regression**
- **K-Nearest Neighbors (KNN)**
- **Decision Tree**

The models are compared using Accuracy, Precision, Recall, F1-score, and ROC-AUC to assess predictive performance 
and identify the best-performing model.

### Best Model
Logistic Regression achieved the best overall performance among the three evaluated models, with 
**88.91% test accuracy** and **85.72% ROC-AUC**.

### Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn

### Project Objective
The objective is to explore how machine learning can support the identification of patients at risk of 
30-day readmission. This project is for educational and research purposes and is not intended for clinical decision-making.
